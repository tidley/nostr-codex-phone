# Pre-Frog-Replacement Assets

This directory preserves the branding assets that shipped before the minimalist
frog replacement.

To restore the previous icons and branding assets:

```sh
tar -xzf assets/branding/pre-frog-replacement/icons.tar.gz
cp assets/branding/pre-frog-replacement/ribbet.png assets/branding/ribbet.png
cp assets/branding/pre-frog-replacement/ribbet-mark.png assets/branding/ribbet-mark.png
```

`minimalist-frog-source.png` is the first supplied frog artwork. The current
frog artwork is retained as `assets/branding/frog-source.png`.
